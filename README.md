# por48.annaserba.ru — страница дома ПОР 48 и 48/1

Статическая страница дома: заявка на добавление в чат дома в MAX.
Сайт ничего не сохраняет: форма собирает сообщение и открывает MAX с готовым текстом.

## Что где

- `index.html` — страница дома и форма.
- `styles.css` — оформление (светлая тема, акценты MAX).
- `app.js` — валидация, телефон, формирование сообщения, запуск MAX.
- `config.js` — ссылка на профиль MAX и диплинк шаринга.
- `privacy.html` — политика обработки данных.
- `avatar.jpg`, `og.jpg`, `favicon.svg` — картинки.

## Как обновить

1. Поправьте `config.js` или текст в `index.html`.
2. Закоммитьте и запушьте:
   ```bash
   git add -A && git commit -m "Обновлена страница дома" && git push
   ```
3. GitHub Pages пересоберёт страницу за 1–2 минуты.

## Домен

`CNAME`: `por48.annaserba.ru`; в GitHub Pages — custom domain
`por48.annaserba.ru` и Enforce HTTPS. DNS: CNAME `por48` → `annaserba.github.io`.

## Форма

Кнопка «Отправить заявку в MAX» открывает `https://max.ru/:share?text=...` —
официальный диплинк MAX, который подставляет текст в экран «Отправить в MAX».
Пользователь выбирает чат Анны и отправляет сообщение. Если вкладка заблокирована,
на странице остаются кнопки «Открыть MAX», «Чат Анны» и «Скопировать текст».
